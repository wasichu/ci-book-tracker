# Reading Log

A local-first reading tracker for language learners.

Principles:

- Mobile first
- Manual entry first
- Local SQLite storage
- No accounts
- No cloud sync
- No social features
- Simplicity over automation

Guidelines:

- Prefer Ash resources and actions.
- Prefer Phoenix LiveView over custom JavaScript.
- Avoid unnecessary dependencies.
- Build the smallest working feature first.
- Desktop layouts are secondary to mobile layouts.
